# Arca — мобильный клиент (Flutter)

Каталог клиента Android/iOS. Интерфейс реализуется в **Фазе 4**. Здесь
закреплены зависимости и правила, которые с первого коммита ограничивают
клиентский код.

## Стек

- **Flutter + Impeller** — отрисовка на 120 Гц.
- **`flutter_rust_bridge` v2** → крейт `crates/arca-ffi` (Фаза 4). Мост только
  передаёт байты файла в `arca-sandbox` и возвращает декодированный
  `XRayReport` / `ArcaRenderTree`. Байты документа идут через FFI без лишнего
  копирования; в песочницу они копируются ровно один раз (см.
  `docs/ARCHITECTURE.md`, §8).

## Обязательные свойства клиента

1. **Ни одного сетевого разрешения.** `AndroidManifest.xml` не содержит
   `android.permission.INTERNET`; на iOS не подключаются сетевые фреймворки.
   Ссылки на поддержку открываются системным браузером (`ACTION_VIEW` /
   `UIApplication.open`), только после явного нажатия.
2. **Никакой телеметрии**: нет SDK аналитики, крэш-репортинга, рекламы,
   удалённой конфигурации.
3. **Документы — только через системный picker и «Поделиться»**: без
   широкого доступа к файловой системе. Каждый документ открывается через
   песочницу, независимо от вердикта.
4. **Экран «О проекте и Поддержка» и «Паспорт Хранителя»** строятся только из
   `arca_attribution::patronage_screen` / `patron_passport`. Карточка
   «Создатели оригинального ядра Arca (Поддержать)» всегда первая.
   Golden-тест вызывает `check_upstream_prominence` для каждой темы и размера
   экрана (`LICENSE_ADDITIONAL_TERMS.md`, пункт 2.3).
5. **Статистика «Паспорта»** хранится локально, в зашифрованном хранилище
   приложения: 36-байтовая запись `PatronStats::encode`.
6. **Оригинальная иконография**: никаких SF Symbols и Material Icons.

## Дизайн-система (Фаза 4)

Темы: Alabaster Studio (светлая), Obsidian Vault (OLED, Smart Document Dark
Mode в OKLCH), Cashmere & Cappuccino, Sierra Blue & Slate, Emerald SecOps,
Desert Titanium. Анимации — критически демпфированные пружины (`mass 1.0`,
`stiffness 480`, `damping 34`), которые можно перехватить жестом. Тактильные
отклики: щит безопасности, фиксация масштаба 100 %, переключение слоёв Visio,
открытие «Паспорта».
