# Arca 0.1.2 — проверка открытия документов и исправления сборки (пре-релиз)

Возможности те же, что в [0.1.0](v0.1.0.md) и [0.1.1](v0.1.1.md). Эта версия в основном про то, что
теперь проверяется автоматически, и про версии.

## Что изменилось

* **Автоматическая проверка теперь открывает документы.** Раньше прогон на эмуляторах только
  запускал приложение и менял размер окна: ни один документ при этом не открывался (скрипт
  не мог передать файл приложению из-за ошибки с кавычками в `adb shell`). Теперь на каждом
  эмуляторе 16 документов (DOCX, DOC, ODT, RTF, PDF, TXT, XLSX, XLS, ODS, CSV, PPTX, PPT, ODP и
  другие) открываются на трёх размерах экрана, и прогон падает, если приложение ответило
  «Не удалось открыть файл» или вылетело. Падением считается только вылет самого приложения:
  сбой чужого процесса образа системы (на API 31 падает `com.android.systemui`) больше не
  портит прогон.
* **Версия движка** на главном экране и в «Диагностике» теперь совпадает с версией
  приложения (раньше показывалась `0.1.0`).
* **Основная проверка кода (`ci`) наконец запускается.** Её файл содержал выражение, которое
  GitHub не принимает, поэтому она не выполнялась ни разу. Исправлено; на Windows перестали
  ломаться тесты Access из-за замены переводов строк в эталонных файлах.

## Что важно знать

* **Это пре-релиз.** Оговорки 0.1.0 остаются в силе: интерфейс на реальных телефонах человеком
  не просматривался, версии под `arm64-v8a` и `armeabi-v7a` на устройствах не запускались
  (эмуляторы — x86_64).
* Документы проверены **на уровне «открылся и показал результат проверки»**; корректность
  самого просмотра по-прежнему обеспечивают тесты ядра на эталонных файлах.
* **Подпись.** Если выше есть блок про одноразовый ключ, пакет подписан ключом, созданным на
  время сборки: обновить его пакетом с другим ключом нельзя — удалите и установите заново.
